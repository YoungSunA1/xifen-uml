系统分析师 · 第 6 章 企业信息化

信息化规划四层结构

教材图 6-2「信息化规划涉及的主要内容和关系」重绘与拆解：四种战略规划各回答哪一层问题、彼此如何依赖，以及考场上最容易混的那一对选项。

一、图 6-2 重绘

  1. 理解关键的企业目标——一切规划的起点：所有规划都应围绕企业关键目标的实现而展开。
  2. 企业如何达到目标——由企业战略规划回答。
  3. 信息系统如何支撑这些目标——由信息系统战略规划回答。
  4. 需要哪些信息技术支撑信息系统——由信息技术战略规划回答。
  5. 信息化建设具体项目的实施——由信息资源规划回答。

二、四种规划的分工（对照表）

规划管什么（记忆短语）回答的问题教材定义要点关注点 / 步骤
企业战略规划 企业方向 企业如何达到目标 用机会和威胁评价现在和未来的环境，用优势和劣势评价企业现状，进而选择和确定企业的总体和长远目标，制定和抉择实现目标的行动方案。 总体目标与长远目标、行动方案（机会—威胁 / 优势—劣势分析）
信息系统战略规划
ISSP，Information System Strategic Planning		 系统架构与业务支撑 信息系统如何支撑这些目标 关注的是如何通过信息系统来支撑业务流程的运作，进而实现企业的关键业务目标。 重点在于对信息系统远景、组成架构、各部分逻辑关系进行规划
信息技术战略规划
通常简称 IT 战略规划		 技术环境 需要哪些信息技术支撑信息系统 在信息系统战略规划的基础上，对支撑信息系统运行的硬件、软件、支撑环境等进行具体的规划，它更关心技术层面的问题。 业务分析 → 检查当前的 IT 架构和信息系统 → 识别机会 → 选择方案（这些步骤构成一个连续统一体，即 IT 战略规划的过程）
信息资源规划
IRP，Information Resource Planning		 数据与标准 信息化建设具体项目的实施 在以上规划的基础上，为开展具体的信息化建设项目而进行的数据需求分析、信息资源标准建立、信息资源整合工作。 面向落地：数据需求、标准、整合，直接支撑具体建设项目

一句话记法（自上而下顺着图 6-2 读）：企业战略规划管企业方向，信息系统战略规划管系统架构与业务支撑，信息技术战略规划管技术环境，信息资源规划管数据与标准。

四个短语是对教材定义的压缩，不是教材原词；其中「系统架构与业务支撑」对应教材原话：对信息系统远景、组成架构、各部分逻辑关系进行规划，并支撑业务流程的运作、实现企业的关键业务目标。

英文全拼说明：教材正文只给出了 IRP 的全拼，ISSP 为通行英文写法，IT 战略规划与「信息技术战略规划」是同一概念。

三、依赖关系：自上而下指导，自下而上支撑

  1. 总体原则：所有的规划都应该围绕企业关键目标的实现而展开，并为企业目标的实现提供支持和必需的服务。
  2. 自上而下的指导链：企业战略规划定目标 → 信息系统战略规划定支撑业务的信息系统远景与架构 → 信息技术战略规划落实硬件、软件与支撑环境 → 信息资源规划做数据需求分析与资源整合 → 进入具体项目的实施。
  3. 自下而上的促进链：通过先进信息系统的支持，完成业务流程的优化，实现企业管理、组织配置与信息技术的结合；反过来，通过业务流程重组和信息资源规划，进一步促进企业信息化规划进程，指导信息系统的设计与实施。
  4. 业务流程重组的定位：它不是与四种规划并列的「第五种规划」，而是贯穿上面四层的问题域。它利用信息技术，对企业的组织结构和工作方法进行「彻底的、根本性的」重新设计，现已成为企业信息化的重要方法。
  5. 一句话记住图的结构：左侧是「领域」，中间是「问题」，右侧是「规划」；四条右箭头由上到下依次是 企业战略规划 → 信息系统战略规划 → 信息技术战略规划 → 信息资源规划，顺序不能颠倒。

四、信息化规划与企业战略规划的关系

信息化阶段需求怎么来形成的信息系统结构
初级阶段 业务部门根据现有的业务流程或管理需要，直接提出信息化需求，IT 部门按需求实施 完全基于企业组织与业务流程的信息系统结构，各个信息系统分别对应于特定部门或特定业务流程
中级阶段 企业已制定整体战略规划，业务部门根据企业战略先改进业务流程和组织结构，再由不同业务部门分别提出需求、IT 部门分别独立实施 与优化后的组织结构和业务流程相适应
高级阶段 依据整体战略规划，通盘考虑各业务部门的信息化需求，制定整体的信息化战略，统一规划、分步实施 由企业信息化战略统一指导，并与优化后的组织结构和业务流程相适应
  1. 互为条件：一方面企业战略的实现已经离不开信息技术和信息系统，企业战略需要信息化战略的支持；另一方面，离开企业战略去规划信息系统，犹如建设海市蜃楼——信息化战略接受企业战略的指导。
  2. 核心问题：企业信息化建设的核心问题是保证企业信息化战略与企业战略的一致性，把企业战略的目标转换为信息系统的战略目标。
  3. 典型后果：很多企业二者分别独立运行、缺乏协调和统一，导致企业战略缺乏信息系统的支撑，同时信息系统缺少企业战略的指导而无效或低效——这是造成「IT 黑洞」的主要原因之一。
  4. 集成方法：业务与 IT 整合（Business-IT Alignment，BITA），以业务为导向、全面的 IT 管理咨询实施方法论，适用于信息系统不能满足当前管理中的业务需要、业务和 IT 之间总是不一致的企业；企业 IT 架构（Enterprise IT Architecture，EITA），分析企业战略、帮助企业制定 IT 战略并指导投资决策，在技术、信息系统、信息、IT 组织和 IT 流程方面建立 IT 的原则规范、模式和标准，适用于现有信息系统和 IT 基础架构不一致、不兼容、缺乏统一的整体管理的企业。两者有相同之处甚至在某些领域重叠，可择一或结合使用。

五、考场秒判：题干关键词 → 选谁

题干出现的表述答案管什么
评价企业现状、（选择和确定）企业的总体和长远目标、制定和抉择实现目标的行动方案企业战略规划企业方向
如何通过信息系统来支撑业务流程的运作，进而实现企业的关键业务目标信息系统战略规划系统架构与业务支撑
对支撑信息系统运行的硬件、软件、支撑环境等进行具体的规划信息技术战略规划（IT 战略规划）技术环境
数据需求分析、信息资源标准建立、信息资源整合，开展具体的信息化建设项目信息资源规划数据与标准

六、易错点

  1. 信息系统战略规划不等于信息技术战略规划：前者的对象是「信息系统」（信息系统远景、组成架构、各部分逻辑关系），后者的对象是「支撑信息系统运行的技术」（硬件、软件、支撑环境）。题干往上谈架构选前者，往下谈设备与环境选后者。
  2. 看动词的宾语：「支撑业务流程的运作、实现关键业务目标」→信息系统战略规划；「支撑信息系统运行」→信息技术战略规划。差别只在宾语那一层。
  3. 企业战略规划的标志词是「评价环境 / 评价现状」「总体和长远目标」「行动方案」，语言是机会与威胁、优势与劣势。
  4. 信息资源规划不是「信息系统的规划」，它是为开展具体信息化建设项目而进行的数据需求分析、标准建立与资源整合，对应图中最底层「信息化建设具体项目的实施」。
  5. 业务流程重组不要当选项去和四种规划并列：它跨列覆盖上面四层，属于企业信息化的重要方法（教材 6.7 节）。
  6. 图 6-2 的读法别搞反：右侧箭头是「规划解答了左侧那一层的问题」，不是左侧问题「产生了」右侧规划。

七、可直接背的句式

  1. 企业信息化规划不仅涉及信息系统规划，同时与企业规划、业务流程建模等紧密相关，是融合企业战略、管理规划、业务流程重组等内容的「业务＋管理＋技术」的规划活动。
  2. 所有的规划，都应该围绕企业关键目标的实现而展开，并为企业目标的实现提供支持和必需的服务。
  3. 企业战略规划回答「企业要达到什么」，信息系统战略规划回答「信息系统如何支撑这些目标」，信息技术战略规划回答「需要哪些信息技术支撑信息系统」，信息资源规划回答「具体信息化建设项目如何实施」。
  4. 信息化规划与企业战略规划总是互相影响、互相促进；二者分别独立运行、缺乏协调和统一，是造成「IT 黑洞」的主要原因之一。
  5. 信息化规划是融合企业战略、管理规划、业务流程重组等内容的综合规划活动，是信息系统设计和实施的前提和依据，其目标是避免信息系统林立、数据资源分散、信息孤岛与重复返工。

八、同节相邻考点（6.3.3 信息系统战略规划方法）

  1. 关键成功因素法（Critical Success Factor，CSF）：识别企业目标对应的关键成功因素，找出实现目标所需要的关键信息集合，从而确定系统开发的优先次序；CSF 是为确保业务流程的成功需要完成的最重要的工作，是业务流程的可观察、可测量的特性。
  2. 战略目标集转化法（Strategy Set Transformation，SST）。
  3. 企业系统规划法（Business System Planning，BSP）：核心是识别企业过程，从而把企业目标转化为系统的目标。
  4. CSB 方法：这三种方法往往结合使用、统称为 CSB 方法，即先用 CSF 确定企业目标，再用 SST 补充完善企业目标，并将其转化为信息系统目标。
  5. 战略栅格：依据现有信息系统和规划中的信息系统的战略影响，确定出战略型、转变型、工厂型、支持型（辅助型）四种信息系统战略规划条件。
  6. 战略一致性模型（Strategic Alignment Model，SAM）：Henderson 于 1994 年提出，用于检查企业战略与信息基础架构之间的一致性，把企业战略规划和信息化战略规划的关系划分为内部领域和外部领域两部分。

CSF、SST、BSP、SAM 的英文全拼为通行写法，教材正文仅给出缩写与中文名称。
